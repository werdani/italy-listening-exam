Google Drive
  1. Carica il file audio su Google Drive
  2. Condivisione → Chiunque abbia il link
  3. Incolla qui il link di condivisione (verrà convertito automaticamente)

Incolla un link Google Drive, un URL https, oppure un percorso tipo assets/audio/q1.mp3.

Il file verrà salvato localmente (base64). Preferisci Drive per GitHub Pages.

Se l’anteprima Drive non parte, controlla che il file sia pubblico «Chiunque abbia il link».
