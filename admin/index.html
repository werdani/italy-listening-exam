GitHub Pages

Pubblicazione automatica

Salva un GitHub Token una volta. Poi ogni modifica può andare online per tutti con Pubblica online (senza export/push manuale).

Crea un token su GitHub → Settings → Developer settings → Personal access tokens. Permesso necessario: Contents: Read and write sul repo werdani/italy-listening-exam. Il token resta solo in questo browser.

Condividi la foto su Drive come Chiunque abbia il link, poi incolla il link qui.

Nuova domanda

Tipo di domanda
Audio / voce
Google Drive
  1. Carica il file audio su Google Drive
  2. Condivisione → Chiunque abbia il link
  3. Incolla qui il link di condivisione (verrà convertito automaticamente)

Incolla un link Google Drive, un URL https, oppure un percorso tipo assets/audio/q1.mp3.

Il file verrà salvato localmente (base64). Preferisci Drive per GitHub Pages.

Se l’anteprima Drive non parte, controlla che il file sia pubblico «Chiunque abbia il link».
